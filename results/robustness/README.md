# Robustness checks

This directory contains additional analyses that test the stability of
the main results. Files here are generated by scripts under
`experiments/` but are kept separate from the primary result files in
`results/`.

## seed_sensitivity.json

Repeats the within-site cross-validation and the cross-site transfer
across five random seeds (0 through 4). For each combination of model,
site, and method, the mean and standard deviation of AUROC, Brier
score, and Expected Calibration Error are reported.

The primary results in `results/baseline.json` and
`results/transfer.json` use seed 42 only. This file shows how much the
metrics vary when the seed changes.

## transfer_temp_scaling.json

Compares four post-hoc calibration methods on the same transfer
setting: raw probabilities, Platt scaling, isotonic regression, and
temperature scaling. Temperature scaling is fitted on the same
calibration split as the other methods.

The primary results in `results/transfer.json` include raw, Platt, and
isotonic. This file adds temperature scaling for comparison without
modifying the primary file.
