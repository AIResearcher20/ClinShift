# Result files

This directory contains the outputs of the experiment scripts. The
files are regenerated by the GitHub Actions workflow on every push to
`main` and committed back to the repository.

## Files

### Phase 1: baseline and transfer

- `baseline.json` — within-site cross-validation results for each of
  the four sites and both model families.
- `transfer.json` — cross-site transfer results, with Platt scaling
  and isotonic calibration applied alongside the raw predictions.

### Phase 2: shift analysis

- `shift.csv` — covariate shift between Cleveland and each target site,
  reported as standardized mean difference for numeric features and
  total variation distance for categorical features. Kolmogorov-
  Smirnov statistic and p-value are included for numeric features.
- `shift_indicators.csv` — unlabeled shift indicators for each target
  site, including both feature-based and prediction-based measures.
  Reported alongside the change in ECE from baseline to transfer.

### Phase 3: concept divergence

- `concept_coefficients.csv` — coefficients of a logistic regression
  fitted independently at each site on a shared feature space.
- `concept_pairwise.csv` — L2 distance between coefficient vectors for
  each pair of sites.
- `concept_prediction_divergence.csv` — mean absolute difference
  between the predictions of site-specific models on the Cleveland
  evaluation set.
- `concept_shift.json` — summary of the two measures above, with
  labeled pairs.

### Ablation

- `ablation_chol.json` — comparison of transfer results with and
  without cholesterol in the shared feature set. The `with_chol` block
  corresponds to an earlier run of the pipeline before the feature was
  excluded.

### Figures

- `figures/` — PNG figures generated by `scripts/make_figures.py`.

## Note on source data

No raw dataset is committed to the repository. The dataset is
downloaded from the UCI machine learning repository at runtime. This
keeps the repository small and ensures that the analysis always uses
the current version of the source archive.
